# ContentForge для Windows

Локальная контент-фабрика: сама берёт актуальные тренды, пишет сценарий, генерирует
кадры и видео, озвучивает, монтирует и публикует выпуск на YouTube.

**Всё содержимое создаётся на вашем ПК.** Из интернета берутся только тренды
(Hacker News, Google News, Reddit) и загрузка готового ролика на YouTube.
Никаких облачных генераторов текста, картинок или голоса.

Версия: 1.0.0 (17.09.2026)

---

## Что внутри

```
ContentForge.bat            меню запуска (двойной клик)
tools\preflight.ps1         проверка системы: Python, Ollama, ComfyUI, FFmpeg, GPU, диски
tools\install.ps1           установка/обновление Python-пакетов
tools\run-factory.ps1       запуск одной проходки завода (Shorts или длинный)
config.example.json         образец настроек
VERSION, CHANGELOG.md       версия и список изменений
```

Сами скрипты завода лежат отдельно (папка фабрики). Приложение находит её
автоматически либо по переменной окружения `CONTENTFORGE_ROOT`.

## Требования

| Компонент | Зачем | Где взять |
|---|---|---|
| Windows 10/11 | — | — |
| Python 3.10+ | запуск завода | python.org (галочка «Add python.exe to PATH») |
| FFmpeg | монтаж и кодирование | ffmpeg.org или winget `Gyan.FFmpeg` |
| Ollama | локальная языковая модель (сценарий) | ollama.com, затем `ollama pull ornith-1.5:9b` |
| ComfyUI + LTXV | генерация кадров и видео | см. репозиторий `ltx-youtube-gold-standard` |
| NVIDIA GPU (8 ГБ+) | ускорение генерации | RTX 3070 и выше достаточно |

Минимум для комфортной работы: 32 ГБ ОЗУ, 20+ ГБ свободного места на рабочем диске.

## Быстрый старт

1. Установите Python, FFmpeg, Ollama и ComfyUI (см. таблицу выше).
2. Пункт **[8] Auto-download** — скачает FFmpeg, предложит поставить Ollama и
   стянет языковую модель. Каждый шаг спрашивает подтверждение.
3. Разверните папку фабрики и пропишите её путь:
   ```
   setx CONTENTFORGE_ROOT "C:\путь\к\фабрике"
   ```
3. Двойной клик по `ContentForge.bat`.
4. Пункт **[1] Check this PC** — убедитесь, что всё на месте и диски не переполнены.
5. Пункт **[2] Install / update Python packages** — один раз.
   Пакеты ставятся в отдельную среду `.venv` внутри папки приложения,
   поэтому ваши собственные Python-библиотеки не затрагиваются.
6. Пункт **[3] Run Shorts factory** или **[4] Run long factory**.

## Режим работы

Оба завода публикуют выпуски **в открытом доступе** и **только по пятницам и субботам**.

| Завод | Дни | Часы | Формат |
|---|---|---|---|
| Длинный (LTX) | пятница, суббота | 11:00 и 18:00 | 16:9, ~1 минута |
| Shorts | пятница, суббота | 07:00, 15:00, 23:00 | 9:16, короткий |

Расписание живёт в планировщике Windows и работает без участия человека:
подъём стека → тренды → сценарий → кадры и видео → сборка → публикация →
уведомление в Telegram.

## Настройки

- `config.example.json` — образец. Рабочий файл кладётся рядом с заводом.
- Пути к ComfyUI и выходным папкам задаются в конфиге завода.
- Публикация: `--privacy public` (открытый доступ) — уже проставлено в расписании.
- Язык выпуска: русский (`--lang ru`).
- Голос: системный, офлайн. Облачные голоса включаются переменной `LTX_TTS_MODE=cloud`,
  но это нарушает правило «только ресурсы ПК».

## Диагностика

| Симптом | Что проверить |
|---|---|
| «Ollama not running» | запустите Ollama; модель должна быть скачана заранее |
| Долгий первый сценарий | прогревайте модель: первый вызов всегда медленнее |
| «cannot cover audio» | мало уникальных кадров в пуле — добавьте кадры или сократите текст |
| Видео не публикуется | проверьте токен YouTube и свободное место на диске |
| Скрипт расписания молча не стартует | файл потерял кодировку UTF-8 BOM |
